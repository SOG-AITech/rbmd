# PEO-LiTFSI data package

- The final workbook is `workbook/run_PEO.xlsx`.
- The historical `linear` and `scaling` case directories retain paired
  `rbmd.log` and `log.lammps` files when both methods were run in one case.
- `lammps_reference/LOG_INDEX.tsv` provides a direct index of all retained
  LAMMPS timing logs.
- RDF/CN analysis scripts, selected curves, plots, and run logs are under
  `rdf`; the large trajectories are listed in the top-level exclusion manifest.
